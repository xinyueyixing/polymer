# 광산란 장비 및 진공 건조기 사용 안내

이 페이지는 광산란 실험을 위한 시료 제작, 진공 건조기 사용 방법, 광산란 장비 측정 방법 및 주의사항을 정리한 문서입니다.  
광산란 장비는 민감한 장비이므로, 처음 사용하는 경우 반드시 실험실 담당자 또는 경험이 있는 선배에게 사용 방법을 확인한 후 사용해야 합니다.

---

## 1. 관련 영상 및 참고자료

광산란 실험과 관련된 참고 영상에는 시료 제작, 광산란 장비 사용법, 장비 문제 발생 시 확인 방법 등이 포함되어 있습니다.

!!! note "참고 영상"
    관련 영상 파일은 용량이 큰 경우가 많으므로 웹사이트에 직접 업로드하지 않는 것이 좋습니다.  
    필요한 경우 실험실 담당자에게 문의하여 영상을 받으시기 바랍니다.

광산란 장비 연결선 관련 사진은 아래 압축 파일을 참고합니다.

    시간이 지나면서 연결 상태가 불안정해질 수 있으므로, 문제가 발생하면 먼저 연결 상태를 확인하고 담당자에게 문의합니다.

## 2. 시료 제작 및 진공 건조

광산란 실험을 하기 전에 시료를 적절히 준비하고, 필요한 경우 진공 건조를 진행합니다.

### 2.1 진공 건조 준비

1. 필요한 양의 시료 또는 약품을 작은 유리병에 넣습니다.
2. 유리병 입구를 알루미늄 호일로 덮습니다.
3. 호일에 작은 구멍을 뚫어 용매가 빠져나갈 수 있도록 합니다.
4. 시료가 들어 있는 유리병을 진공 건조기에 넣습니다.
5. 진공 건조기 문을 닫습니다.

---

### 2.2 진공 건조기 작동

1. 진공펌프와 냉각 장치를 켭니다.
2. 냉각 온도가 목표 온도에 도달할 때까지 기다립니다.
3. 진공 건조기 전원을 켭니다.
4. 온도를 설정합니다.
    - 화면 표시가 `C`에서 `Su`로 바뀐 후 온도를 조절합니다.
    - 화살표 버튼을 눌러 원하는 온도로 설정합니다.
5. 아래쪽 손잡이 또는 밸브를 조절하여 진공 상태를 만듭니다.

!!! warning "주의"
    시료에 따라 적절한 온도와 건조 시간이 다를 수 있습니다.  
    처음 진행하는 시료는 반드시 담당자에게 조건을 확인한 후 실험합니다.

---

## 3. 샘플링 방법

광산란 실험용 샘플은 먼지나 기포가 들어가지 않도록 주의해서 준비해야 합니다.

1. 가열판 위에 유리판을 올립니다.
2. 테이프 가운데에 작은 구멍을 만든 뒤 유리판 위에 붙입니다.
3. 테이프 가장자리가 들뜨지 않도록 단단히 붙입니다.
4. 시료 용액을 테이프 가운데 구멍에 넣습니다.
5. 자연 건조 또는 필요한 조건에서 건조합니다.
6. 건조 중 기포가 생기지 않도록 주의합니다.

!!! warning "주의"
    시료 안에 기포가 생기면 광산란 측정 결과에 영향을 줄 수 있습니다.  
    샘플링할 때 먼지와 기포가 들어가지 않도록 주의합니다.

---

## 4. 광산란 장비 측정 방법

광산란 장비를 사용할 때에는 장비 전용 컴퓨터와 프로그램을 사용합니다.

### 4.1 측정 전 준비

1. 광산란 장비와 연결된 컴퓨터를 켭니다.
2. `Temp` 프로그램을 실행합니다.
3. 신호가 정상적으로 들어오는지 확인합니다.
4. 필요한 온도 범위를 설정합니다.
5. 시료를 장비 위에 올립니다.
6. 빛이 시료의 투명한 부분 또는 구멍을 통과하는지 확인합니다.

---

### 4.2 프로그램 설정 및 측정

1. 컴퓨터 프로그램에서 `Time off`를 클릭합니다.
2. 목표 온도와 승온 속도를 설정합니다.
3. 온도 입력 시 숫자 키패드가 아니라 키보드 상단 숫자키를 사용합니다.
4. `lock_excel`을 클릭하여 데이터를 Excel에 저장합니다.
5. 실험이 끝난 후 다시 `Time off`를 클릭합니다.

!!! warning "중요"
    광산란 장비용 컴퓨터는 오래된 시스템이므로 갑자기 멈추거나 오류가 발생할 수 있습니다.  
    실험 중에는 불필요한 작업을 하지 않는 것이 좋습니다.

---

## 5. 데이터 저장 및 처리 시 주의사항

광산란 실험 데이터는 반드시 안전하게 저장해야 합니다.

주의사항은 아래와 같습니다.

- 광산란 장비용 컴퓨터에서 여러 창을 동시에 많이 열지 않습니다.
- 원본 데이터 파일을 직접 수정하지 않습니다.
- 원본 Excel 파일은 그대로 보관하고, 복사본에서 데이터를 처리합니다.
- 한 단계 작업이 끝난 후 다음 단계로 진행합니다.
- 데이터는 실험실 컴퓨터에서 바로 처리하지 말고, 개인 컴퓨터로 옮긴 뒤 처리하는 것이 좋습니다.
- 중요한 데이터는 개인 컴퓨터와 서버 또는 외부 저장장치에 백업합니다.

!!! danger "주의"
    광산란 장비용 컴퓨터가 멈추면 데이터가 손실될 수 있습니다.  
    실험 중에는 반드시 천천히 조작하고, 불필요한 프로그램을 실행하지 않습니다.

---

## 6. 장비 문제 발생 시

광산란 장비 또는 전용 컴퓨터에 문제가 발생한 경우, 임의로 여러 번 조작하지 않습니다.

확인 순서는 아래와 같습니다.

1. 프로그램이 정상적으로 실행되는지 확인
2. 온도 신호가 들어오는지 확인
3. 장비 연결선이 빠지지 않았는지 확인
4. 시료 위치가 맞는지 확인
5. 빛이 샘플을 통과하는지 확인
6. 문제가 계속되면 담당자에게 문의

!!! warning "주의"
    광산란 장비의 연결선이나 내부 부품은 임의로 분리하거나 변경하지 않습니다.  
    문제가 해결되지 않으면 반드시 담당자에게 도움을 요청합니다.

- [ ] 온도 범위 및 승온 속도 확인
- [ ] 시료 위치 확인
- [ ] Excel 저장 설정 확인
- [ ] 원본 데이터 백업
- [ ] 측정 후 장비 주변 정리

## 8. 참고사항

광산란 장비는 작은 설정 차이나 시료 상태에 따라 결과가 달라질 수 있습니다.  
문제가 생겼을 때 혼자 해결하려고 하지 않는 것이 좋습니다.

특히 장비용 컴퓨터는 오래된 시스템이므로, 실험 중 불필요한 창을 열거나 원본 파일을 직접 수정하지 않도록 주의해야 합니다.
